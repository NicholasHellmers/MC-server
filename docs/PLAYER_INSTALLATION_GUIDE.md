# Player Installation Guide: Cobblemon Adventure

Welcome to the **Cobblemon Adventure Server**! Follow these quick steps to install the modpack and connect to our server.

---

## Prerequisites
* **Minecraft Java Edition** (Minecraft 1.21.1)
* **Modrinth App** (Recommended) or **Prism Launcher**
  * Download Modrinth App for free at: [modrinth.com/app](https://modrinth.com/app)

---

## 3-Step Quickstart (Modrinth App)

### Step 1: Download the Modpack File
1. Go to the `#modpack-updates` or `#announcements` channel in our Discord server.
2. Download the latest `Cobblemon-Modpack-vX.Y.Z.mrpack` file attached to the release message.

---

### Step 2: Import into Modrinth App
1. Open the **Modrinth App**.
2. Click the **`+` (Add Instance)** button on the left sidebar.
3. Select **From File** (or simply drag and drop the downloaded `.mrpack` file directly into the Modrinth window).
4. Modrinth will automatically download and install all required mods, textures, and custom configs.

---

### Step 3: Launch & Connect
1. Click **Play** on your new Cobblemon instance in Modrinth App.
2. Once the game reaches the main menu, click **Multiplayer**.
3. Add or join our server:
   * **Server Address:** `play.cobblemon.xyz` *(or the static IP provided in Discord)*
4. Enjoy playing Cobblemon!

---

## How to Update When a New Release Drops

When a new update is announced in Discord:
1. Download the new `Cobblemon-Modpack-vX.Y.Z.mrpack` from Discord.
2. In Modrinth App, open your Cobblemon instance options &rarr; **Update from file** (or drag & drop the new `.mrpack` over your existing instance).
3. Modrinth will update only the changed mods and configs in seconds without resetting your singleplayer worlds or keybindings.
