# Code Coverage Report & 100% Enforcement Skill

This skill guides the inspection of test coverage across the repository and ensures that all Python modules in `src/` and `cicd/` achieve 100% line and branch coverage.

## Running Test Coverage

To run the complete test suite and generate coverage reports:

```bash
uv run pytest --cov=src --cov=cicd --cov-report=term-missing --cov-report=json --cov-fail-under=100
```

## Inspecting Uncovered Lines

If test coverage is below 100%, execute the coverage analyzer:

```bash
uv run python .agents/skills/code-coverage-report/scripts/check_coverage.py coverage.json
```

## Resolution Workflow

1. Read the reported missing line numbers and missing branches.
2. View the target source file around those line numbers.
3. Identify the unreached condition, exception clause, or edge case.
4. Add parameterized test cases in `tests/` mocking the relevant inputs or error conditions.
5. Re-run `uv run pytest` to confirm 100% coverage is restored.
